# Connplex B2B & Vista .NET Integration Architecture & Operational Handbook

## 1. Executive Summary & Source of Truth

This document outlines the architectural standard, operational procedures, and production contracts governing the integration between **Connplex B2B Application** and **Vista .NET Cinema Management System**.

Vista is the centralized, external Cinema Management System (CMS) and immutable financial source of truth for Connplex's network of 50 franchise and corporate cinemas across India. Under no circumstances is Vista source code modified or are individual cinema POS machines contacted directly from the browser. The B2B backend acts as an authenticated, multi-tenant integration adapter.

---

## 2. Verified Vista .NET WebService API Contracts

Extracted directly from Vista C# production source code (`Vista/App_Code/api.cs`, `Vista/App_Code/Common.cs`, and `Vista/Database/FranchiseDashboard_Schema.sql`):

### 2.1 Primary Revenue API
- **Endpoint:** `POST {VISTA_BASE_URL}/api.asmx/GetFranchiseRevenueDashboard`
- **Headers:** `Content-Type: application/json; charset=utf-8`
- **Request Payload:**
  ```json
  {
    "CinemaID": "CL16",
    "FromDate": "2026-10-01",
    "ToDate": "2026-10-05"
  }
  ```
- **Response Format:**
  ASP.NET ScriptService wraps the response inside property `d` as serialized JSON. The B2B `VistaClient` unwraps `response.data.d` to extract `Summary` and `DailyBreakdown` (`Date`, `TicketsSold`, `TicketRevenue`, `FnBItemsSold`, `FnBRevenue`, `TotalDailyRevenue`, `DailyATP`, `DailySPH`).

### 2.2 Cinema Discovery API
- **Endpoint:** `POST {VISTA_BASE_URL}/api.asmx/GetAllcinemaDetails`
- **Request Payload:** `{}`
- **Response Format:**
  Returns `ItemCinemaDetails` array with `Cinema_strName`, `Cinema_strID`, and `License_strCode`.

### 2.3 Nightly Audit API
- **Endpoint:** `POST {VISTA_BASE_URL}/api.asmx/GetDailySalesAndFnbReport`
- **Request Payload:**
  ```json
  {
    "CinemaID": "CL16",
    "Date": "2026-10-04"
  }
  ```
- **Response Format:**
  Returns `salesDataXml` string generated by Vista's `objBook.strBMSSalesData(CinemaID, date, date)` for End-of-Day (EOD) settlement audit.

## 3. Strict Non-Additive Accounting Standard

> [!CAUTION]
> **ZERO DOUBLE-COUNTING MANDATE**  
> BookMyShow and Connplex Website bookings commit directly into Vista's local/central database (`tblTrans` and `tblTransTicket` with `strTransStatus = 'C'`).  
> **Therefore, Vista's reported `TicketRevenue` and `TotalDailyRevenue` ALREADY INCLUDE BookMyShow and Website sales.**

### Core Formulas:
1. **Total Gross Revenue:**
   $$\text{Total Gross Revenue} = \text{Box Office Ticket Revenue} + \text{F\&B Concessions Revenue}$$
2. **Box Office Channel Attribution:**
   $$\text{Box Office Ticket Revenue} = \text{Counter} + \text{BookMyShow} + \text{Website} + \text{Other}$$
3. **Walk-in Counter Revenue:**
   $$\text{Counter Revenue} = \text{Box Office Ticket Revenue} - (\text{BookMyShow} + \text{Website} + \text{Other})$$

BookMyShow and Connplex Website revenues are channel attributions of the box office total, never additions to it.

## 4. Multi-Tenant Server-Side Security Model

1. **Franchise Owners:**
   - Evaluated server-side from session/token credentials.
   - Forcibly locked to their assigned cinema (`FR-${user.cinemaId}`).
   - Any query override (`?franchiseCode=...` or request body override) is discarded and locked to their authorized cinema.
2. **Corporate Administrators:**
   - Full network rollup access across all 50 franchise locations.
   - Comparative rankings, multi-cinema drill-down, and sync controls.

## 5. Background Synchronization & Resilience

- **10-Minute Revenue Worker:** Loops over all active cinemas, queries Vista `GetFranchiseRevenueDashboard`, normalizes channel distributions, and performs atomic upserts on compound unique key `{ franchiseCode: 1, businessDate: 1 }`.
- **2:00 AM IST Nightly Audit:** Queries `GetDailySalesAndFnbReport`, parses `salesDataXml`, compares with B2B daily records, and logs variances into `ReconciliationAudit`.
- **4:00 AM IST Cinema Discovery:** Discovers new cinema entries from Vista `GetAllcinemaDetails`.
- **Timezone Boundary:** Cinema operating day runs 06:00 AM to 05:59 AM next morning in `Asia/Kolkata` (IST).
